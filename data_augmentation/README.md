# Data Augmentation Comparison

Data augmentation was evaluated as part of the model-development pipeline to improve generalization and reduce sensitivity to variations in waste appearance and image conditions.

Two augmentation strategies were tested:

1. **Light augmentation**
2. **Medium augmentation**

Each configuration was trained under the same general experimental setup, and the resulting performance metrics were recorded in separate CSV files.

These results were compared using metrics such as precision, recall, mAP@50, and mAP@50–95 to determine the more suitable augmentation strategy for the final model-development stage.
